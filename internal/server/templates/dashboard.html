Core Operational Workflow

  1. Register Node: Add server host/IP and user. Use Auto-Inject SSH Key or authorize manually in ~/.ssh/authorized_keys.
  2. Define Stack: Create standard docker-compose.yml templates with default environment variables.
  3. Deploy & Run: Assign stack to node. Docker Orkes uploads compose files via SFTP and runs docker compose up -d over SSH.
  4. Monitor & Drift Check: Observe disk/containers, browse remote files live, and detect drift between Control Plane Desired State and remote Actual State.
